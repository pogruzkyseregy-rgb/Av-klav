# AvrorA Klav

Клавиатура для Android в стиле Авроры.

## Что умеет

- Раскладки: русская (ЙЦУКЕН), английская (QWERTY), символы и цифры, переключение RU/EN.
- Буфер обмена: сохраняет всё, что копируешь (до 60 записей). Нажми на запись, чтобы вставить. ★ закрепляет запись наверху, ✕ удаляет.
- Фон: любая картинка из галереи. В настройках сразу виден предпросмотр фона и клавиш.
- Визуал внутри клавиатуры (кнопка ⚙): затемнение фона, прозрачность клавиш, звук, вибрация, глитч при нажатии, заглавная буква после точки.
- Пробел: короткое нажатие печатает пробел, удержание и движение пальца двигают курсор.
- Удержание backspace удаляет текст непрерывно.

## Сборка через GitHub

Каждый push в `main` запускает сборку. Готовый APK: Actions → последний запуск → Artifacts → `AvrorA-Klav`.

## Обновления

APK подписан постоянным ключом `keystore/avrora-klav.jks`, поэтому новая версия ставится поверх старой без удаления.
Перед каждым релизом увеличивай `versionCode` в `app/build.gradle.kts`, иначе Android не примет обновление.

Первая установка сборки 0.2.0 поверх сборки 0.1.0 (подписанной другим ключом) потребует один раз удалить старую версию.

## Установка

1. Скачай APK и установи его (разреши установку из неизвестных источников).
2. Открой AvrorA Klav и нажми «Включить клавиатуру», затем «Выбрать клавиатуру».
