# AvrorA Klav

Клавиатура для Android в стиле Авроры.

## Что умеет

- Раскладки: русская (ЙЦУКЕН), английская (QWERTY), символы и цифры.
- Буфер обмена: сохраняет всё, что ты копируешь, до 60 записей. Нажми на запись, чтобы вставить. Звёздочка закрепляет запись наверху, крестик удаляет.
- Фон: выбери любую картинку из галереи и задай затемнение, чтобы клавиши хорошо читались.
- Удержание backspace удаляет текст непрерывно.

## Сборка через GitHub

Каждый push в ветку `main` запускает сборку. Готовый APK:
Actions → Build APK → последний запуск → Artifacts → `AvrorA-Klav-debug`.

Можно также запустить сборку вручную: Actions → Build APK → Run workflow.

## Установка

1. Скачай APK и установи его (разреши установку из неизвестных источников).
2. Открой приложение AvrorA Klav.
3. Нажми «Включить клавиатуру», затем «Выбрать клавиатуру».

## Ограничения первой версии

- Буфер сохраняется только тогда, когда клавиатура запущена. Android не даёт клавиатуре следить за буфером в фоне.
- Свайп-ввод, автокоррекция и словарь пока не реализованы.
